# Cell-Aware Simulation using SPICE

This tool performs a SPICE simulation of the cells in the provided cell library.
For each cell defects are inserted and the cell response is simulated via SPICE.
The cell responses (inputs and outputs) are then transformed into a fault model for automatic test pattern generation (ATPG).
